## 🧠 Anotações Principais
- A linha de comando é muito mais poderosa do que uma interface gráfica.
- O próprio Microsoft Word é uma ferramenta que é dita como "mais confusa" na interface gráfica do que na linha de comando.
- Outro ponto são os acessos remotos, ao invés de utilizar ferramentas como Anydesk ou TeamViewer o SSH é muito mais leve e eficiente.
- Dificilmente um servidor Unix possui uma interface gráfica
- Referente aos comandos iniciais no Linux, está disponível a seguir um documento com as informações relacionadas a comandos no Linux: [[secao01-Linux Cheat Sheet V1.0.pdf]]
- su -> altera o usuário de X para root(privilégios admin)
	- Caso você esqueça de realizar o logoff o usuário com privilégios admin mantém o login.
- sudo -> Super User Do
	- Você vai executar com privilégios do root, porém logado no seu usuário e possuindo um risco menor.
